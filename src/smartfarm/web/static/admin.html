관리자 비밀번호가 설정되지 않았습니다

라즈베리 파이에서 아래 명령으로 비밀번호를 설정한 뒤 웹서버를 재시작하세요.

cd ~/smartfarm
PYTHONPATH=src .venv/bin/python -m smartfarm.web.admin_password
systemctl --user restart smartfarm-web

숫자 4자리 PIN 또는 10자 이상 비밀번호로 정할 수 있습니다.

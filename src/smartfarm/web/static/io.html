시운전 순서 (처음 설치할 때)
  1. 전체 정지 — 자동 운전을 멈춰야 릴레이 시험을 할 수 있습니다.
  2. 버스 추가 — Modbus TCP 게이트웨이(IP·포트) 또는 USB-RS485(포트·속도). 장비 없이 연습하려면 "시뮬레이터".
  3. 장치 검색 — 버스에서 응답하는 국번을 찾아 장치(릴레이 보드·센서)로 등록. 국번이 겹치면 통신이 안 됩니다.
  4. 릴레이 시험 → 할당 — "시험"을 누르면 그 릴레이만 몇 초 켜집니다. 현장에서 움직인 장비를 보고 출력(예: 관수 3구역)을 지정.
  5. 센서 할당 — 측정값을 확인하며 이름(예: temp_z1)을 붙입니다. 구역 제어의 히터·팬 설정에서 이 센서를 고릅니다.
  6. 자동 운전 재개.

구성은 저장 즉시(1초 안에) 측정 서버에 반영됩니다. 할당을 바꾸면 이전 릴레이는 자동으로 꺼집니다.

실제 장치가 등록되어 있습니다. 4자리 PIN 으로는 제어·구성 변경이 막힙니다 — 10자 이상 비밀번호로 바꾸세요.

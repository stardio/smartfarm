# 필드 I/O (Modbus) · I/O 할당 · 시운전

화면: **https://smartfarm-pi.tail084a13.ts.net/io** (관리자 로그인 필요, 제어 화면 상단 링크)

Pi GPIO 는 쓰지 않는다(3.3V 비절연). 모든 출력·센서는 **RS485/이더넷 Modbus 장비**로 연결하고,
어느 보드의 몇 번 릴레이가 어떤 출력(관수 3구역 등)인지는 **배선 후 이 화면에서 지정**한다.

## 1. 지원 범위

| 항목 | 내용 |
|---|---|
| 통신 버스 | **Modbus TCP**(게이트웨이·이더넷 릴레이 보드), **Modbus RTU**(USB-RS485, pyserial), **시뮬레이터**(장비 없이 연습 — 국번 1·2 = 16채널 릴레이, 3·4 = 온습도 센서가 미리 연결됨) |
| 기능 코드 | 01·02·03·04 읽기, 05·06·15 쓰기 (외부 Modbus 라이브러리 없이 직접 구현) |
| 릴레이 프로파일 | `relay_coil` 코일 방식(FC05/FC15, 상태 FC01) · `relay_register` 레지스터 방식(FC06 0x0100 켜기/0x0200 끄기, 상태 FC03). 채널 수·시작 번지·켜기/끄기 값·상태 읽기 방식은 장치마다 변경 가능 |
| 센서 프로파일 | `th_sensor` 온습도(FC04 1·2번지 ×0.1) · `th_sensor_holding`(FC03 0·1번지) · `custom_sensor`(번지·배율 직접 입력) |
| 측정 종류 | 온도·습도·pH·EC (CO₂·수위·유량은 추가 예정) |

새 장비는 설명서의 **Modbus 레지스터 표**를 보고 기존 프로파일 옵션으로 맞추거나,
`src/smartfarm/fieldio/profiles.py` 에 프로파일을 추가한다.

## 2. 시운전 순서

1. **전체 정지** (화면 오른쪽 위) — 자동 운전이 멈춰야 릴레이 시험 가능
2. **버스 추가**
   - TCP: 게이트웨이 IP·포트(보통 502). 게이트웨이는 "Modbus TCP ↔ RTU 변환" 모드로 설정
   - RTU: `/dev/ttyUSB0` 또는 고정 이름 `/dev/serial/by-id/…`(권장 — 변환기를 여러 개 쓰면 번호가 바뀔 수 있음), 속도·패리티는 장비 설명서대로(보통 9600 N 8 1)
3. **장치 검색** → 응답한 국번을 **장치로 등록**(프로파일 선택). 국번은 버스 안에서 겹치면 안 됨
4. **릴레이 시험(3초)** → 현장에서 움직인 장비 확인 → **할당** 드롭다운에서 출력 선택(즉시 저장)
5. **센서 할당** — 센서 장치 카드의 측정값을 확인하고 이름 지정(예: `temp_z1`).
   번지를 모르면 **레지스터 읽기**로 확인. 할당한 센서는 구역 제어의 히터·팬 온도센서 목록에 나타남
6. **자동 운전 재개**

## 3. 동작·안전

- 할당되지 않은 출력은 계속 **시뮬레이션**(제어 화면 카드의 "출력:" 줄에 표시)
- 장치가 **처음 연결되면 그 보드의 릴레이를 모두 끈 뒤** 명령 상태를 맞춤
- 릴레이 상태를 2초마다 다시 읽어 명령과 다르면 다시 씀(보드 재부팅·노이즈 대비)
- 연속 3회 통신 실패 → **"통신 끊김" 텔레그램 알림**, 제어 카드에 ⚠ 표시. 5초마다 재접속,
  복구되면 알림 후 마지막 명령 상태로 맞춤
- 할당을 바꾸거나 해제하면 이전 릴레이는 자동으로 꺼짐
- 릴레이 시험은 **전체 정지 상태에서만**, 1~10초
- **실제 장치(시뮬레이터 아닌 버스)를 등록하면 4자리 PIN 으로는 제어·구성 변경 불가** → 10자 이상 비밀번호 필요
  (`PYTHONPATH=src .venv/bin/python -m smartfarm.web.admin_password`)
- 모든 구성 변경은 `control.db` 의 `events` 에 기록

### ⚠ 하드웨어로 보완해야 할 점
Pi 나 통신이 멈추면 **릴레이는 마지막 상태를 유지**한다(대부분의 Modbus 릴레이 보드).
관수 밸브가 열린 채 멈추는 일을 막으려면 다음 중 하나 이상을 권장:
- **통신 감시(워치독) 기능이 있는 릴레이 보드** — 일정 시간 명령이 없으면 전체 OFF
- 관수·양액 회로에 **하드웨어 타이머/유량·수위 인터록**
- 히터에 **기계식 과열 차단기**(바이메탈) — 소프트웨어와 별개

## 4. 구조

```
웹 /io ──구성 저장──▶ control.db (io_buses, io_devices, io_map, io_sensors)
       └─시험·검색·읽기 명령─▶ commands ──▶ 제어기 ──▶ I/O 관리자 작업 스레드
제어기 ─ MappedOutput("irrigation.3") ─▶ I/O 관리자 ─▶ io_map ─▶ 보드 #릴레이 (Modbus 쓰기)
I/O 관리자 폴링(0.5초 루프): 릴레이 2초, 센서 5초, 끊긴 장치 5초 재시도 → data/io.json
측정 루프(10초) ◀─ ModbusSensor ◀─ I/O 관리자가 읽어 둔 값 (20초 넘게 오래되면 "값 없음")
```
